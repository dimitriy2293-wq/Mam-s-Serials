# Serial Bot — AI-сериалы в Telegram

## Установка
```bash
npm install
```
Нужен установленный `ffmpeg` на машине, где будет крутиться бот:
```bash
apt install ffmpeg   # Linux
```

## Настройка
1. Скопируй `.env.example` в `.env` и заполни:
   - `TELEGRAM_BOT_TOKEN` — от @BotFather
   - `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` — из настроек Supabase проекта (Settings → API)
   - `GEMINI_API_KEY` — из Google AI Studio
   - `WAVESPEED_API_KEY` — с wavespeed.ai/accesskey (картинки персонажей/сцен + видео)

2. В Supabase (SQL Editor) выполни содержимое `schema.sql` — создаст таблицы `episodes` и `scenes`.

3. Бакет для хранения сгенерированных фото/аудио/видео (`serial-bot-assets`) создаётся автоматически при первом запуске бота (`lib/storage.js` → `ensureBucket()`), делать вручную не нужно.

## Запуск
```bash
npm start
```

## Как это работает
1. `/new_episode` → пользователь выбирает: свой черновик сюжета или генерация с нуля
2. Gemini дорабатывает/пишет сценарий, разбивает на сцены по 5 сек, определяет всех персонажей сюжета
3. Пользователь выбирает: прислать свои фото персонажей (с именами) или сгенерировать всех через ИИ — можно прислать несколько фото подряд, недостающих персонажей бот сгенерирует сам
4. Показывается ориентировочная стоимость в $ (WaveSpeed) перед стартом генерации
5. Каждая сцена генерируется через WaveSpeed (Nano Banana 2 — композитный кадр сцены, Wan 2.2 — image-to-video) + озвучка через Gemini TTS
6. Бот поллит статус генерации, после готовности всех сцен склеивает эпизод через ffmpeg и присылает видео

## Как собирается кадр каждой сцены
Перед генерацией видео для **каждой** сцены (не только многоперсонажной) бот сначала просит WaveSpeed (Nano Banana 2 Edit) собрать полный референс-кадр: персонаж(и) сцены (из их фото) + фон/декорация по описанию сцены из сценария (`generateSceneReferenceImage` в `lib/wavespeed.js`). Именно этот собранный кадр — единственный референс, который уходит в Wan 2.2 (image-to-video, тоже через WaveSpeed). Так фон и обстановка соответствуют сценарию, а не остаются дефолтным пустым фоном с фото персонажа. Если генерация кадра недоступна (например, кончились кредиты) — бот тихо откатывается на фото персонажа напрямую, фон всё равно попадёт в кадр через текстовый промпт.
