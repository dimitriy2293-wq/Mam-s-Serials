# Фоновая музыка для коротких видео (необязательно)

По умолчанию бот сам синтезирует тихую амбиентную подложку под каждый ролик
(`lib/background-music.js`) — ничего класть сюда не обязательно, музыка будет
добавлена автоматически без каких-либо файлов и без вопросов авторских прав
(звук генерируется процедурно через ffmpeg).

Если хочешь более "живое" звучание — можешь положить сюда свои `.mp3`/`.wav`/`.m4a`
файлы, и бот будет случайно брать один из них ВМЕСТО автогенерации (громкость
регулируется `SHORTS_MUSIC_VOLUME` в `.env`, по умолчанию `0.12`).

**Важно про авторские права, если решишь добавить свои файлы:** используй только
треки, на которые у тебя есть права — royalty-free/CC0 библиотеки (YouTube Audio
Library, Pixabay Music, Free Music Archive с лицензией CC0) или собственную музыку.
Не клади сюда треки популярных исполнителей — в TikTok/YouTube это словит Content ID.
