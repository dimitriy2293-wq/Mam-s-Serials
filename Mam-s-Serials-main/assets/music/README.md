# Фоновая музыка для коротких видео

Положи сюда один или несколько `.mp3`/`.wav`/`.m4a` файлов — `lib/shorts-assemble.js`
при сборке каждого ролика будет случайно брать один из них, тихо накладывать под
озвучку (громкость регулируется переменной `SHORTS_MUSIC_VOLUME` в `.env`, по
умолчанию `0.12`) и зацикливать/обрезать под длительность ролика.

Если папка пустая — ролик соберётся без фоновой музыки, ошибки не будет.

**Важно про авторские права:** используй только треки, на которые у тебя есть
права — royalty-free/CC0 библиотеки (например YouTube Audio Library, Pixabay
Music, Free Music Archive с лицензией CC0) или собственная музыка. Не клади
сюда треки популярных исполнителей — если ролики с ними попадут в TikTok/YouTube,
это гарантированно словит Content ID и может привести к бану аккаунта.
